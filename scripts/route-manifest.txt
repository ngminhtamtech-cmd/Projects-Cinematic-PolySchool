# VAN DE GOC
#   Script route-baseline.bat cu kiem cac route KHONG CON TON TAI (/auth/login,
#   /booking/history, /api/v1/catalog/films). Chung tra 404, va vi file baseline goc
#   cung chua dung 404 do nen script bao "0 route hoi quy" — mot mau xanh gia. Route
#   that (/login, /orders/history, /api/v1/films) thi khong he duoc kiem.

# CACH LAM MOI
#   File nay khai bao TUNG route kem MA HTTP KY VONG theo trang thai dang nhap.
#   404 khong bao gio duoc coi la "tot" cho mot route bat buoc: neu route can ton tai
#   ma tra 404 thi day la loi, khong phai baseline.
#
#   Danh sach duoc doi chieu voi <url-pattern> trong WEB-INF/web.xml.
#
# DINH DANG
#   <duong-dan> <ky-vong-khi-an-danh> <ky-vong-khi-la-admin>
#
#   Ma ky vong co the la mot so (200) hoac nhieu so cach nhau boi "|" (302|401).
#   Dong bat dau bang # la ghi chu.
